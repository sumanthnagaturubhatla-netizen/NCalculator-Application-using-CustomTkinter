# NCalculator Application using CustomTkinter

## Overview

NCalculator is a modern desktop-based calculator application developed using Python and CustomTkinter. The application was designed to provide multiple utility features within a single platform, offering users a clean graphical interface and an enhanced calculation experience.

Apart from performing standard arithmetic calculations, the application also includes multiple conversion utilities such as currency conversion, unit conversion, length conversion, and weight conversion. Voice integration functionality was additionally implemented to improve user interaction and accessibility.

The project demonstrates GUI development, modular programming, and Python application design using CustomTkinter.

# Functional Modules

## 1. Basic Calculator

Performs arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division
* Percentage Calculations

## 2. Currency Converter

Converts one currency into another based on predefined conversion values.

## 3. Unit Converter

Supports conversion between different measurement units.

## 4. Length Converter

Converts units such as:

* Meter
* Kilometer
* Centimeter
* Millimeter

## 5. Weight Converter

Supports weight conversion between:

* Kilograms
* Grams
* Pounds

## 6. Voice Integration

Provides voice output support for calculations and improves user interaction.
